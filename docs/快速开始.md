# 快速开始：sp500 / nasdaq100 与本仓库到底是什么

## 1. 先澄清三件事（很重要）

### 本仓库有没有「克隆」研究报告里提到的那些 GitHub 项目？

**没有。** 两份 Markdown（《量化交易模型研究报告》《AI美股程序化交易研究报告》）是放在本目录里的 **调研笔记 / 参考书**，**不是**把 [freqtrade](https://github.com/freqtrade/freqtrade)、[Qlib 源码仓库](https://github.com/microsoft/qlib)、[FinRL](https://github.com/AI4Finance-Foundation/FinRL) 等 **整库 clone 进来**。

本项目的做法是：

- 用 **`pip install -r requirements.txt`** 安装 **PyPI 上的包**（例如 `pyqlib`、`vectorbt`、`alpaca-py`），在本地虚拟环境 `.venv` 里用；
- 再加上 **本仓库自己的脚本**（`scripts/`）、**配置**（`config/qlib/`）和 **文档**（`docs/`、`*.md`）。

所以：**研究报告里列的是「业界常用项目清单」；本仓库是「基于其中部分库搭的一套最小可跑骨架」**，二者不是「同一份代码拷贝」。

### sp500、nasdaq100 在本项目里是什么？

它们是 **Qlib 官方美股示例数据包**里自带的 **股票池名字**，对应磁盘上的列表文件，例如：

- `~/.qlib/qlib_data/us_data/instruments/sp500.txt`
- `~/.qlib/qlib_data/us_data/instruments/nasdaq100.txt`

你运行 `scripts/download_qlib_us.py` 下载数据后，这些池子就可以被 **YAML 里的 `instruments: sp500` / `nasdaq100`** 或脚本里的 `--market sp500` 使用。**不是**本仓库单独维护的一套「克隆来的指数成分股工程」。

### 「演示」跑出来的东西看不懂怎么办？

下面第 3 节用白话解释 **`qrun` 终端里常见几行** 和 **流动性选股脚本的表**。若你点的是 **MLflow / `mlruns`** 里的实验，那是图形化看同一次训练与回测，核心指标与终端里打印的是一类东西。

## 2. 使用 sp500 / nasdaq100：推荐顺序（复制执行）

在项目根目录（已建好 `.venv` 并装过依赖的前提下）：

```bash
# 1）数据（只需一次或偶尔更新）
.venv/bin/python scripts/download_qlib_us.py
.venv/bin/python scripts/verify_data_sources.py

# 2）先看「规则选股」表（最容易懂）：在池子里按流动性排名
.venv/bin/python scripts/screen_liquidity_qlib.py --market nasdaq100 --top 15
.venv/bin/python scripts/screen_liquidity_qlib.py --market sp500 --top 15

# 3）再跑「机器学习 + 组合回测」（输出会多，见下一节）
#    较快：nasdaq100
make qrun-ndx
# 或：.venv/bin/qrun config/qlib/workflow_lightgbm_alpha158_us_nasdaq100.yaml

#    更全、更慢：sp500
make qrun-sp500
# 或：.venv/bin/qrun config/qlib/workflow_lightgbm_alpha158_us.yaml
```

改池子 = 改 YAML 里的 `market: &market nasdaq100` / `sp500`，或改脚本参数 `--market`。

## 3. 输出里常见内容是什么意思（白话）

### A）`screen_liquidity_qlib.py` 打出来的表

| 列 | 含义 |
|----|------|
| `symbol` | 股票代码 |
| `avg_dollar_vol_20d` | 近 20 个交易日「平均成交额」≈ 股价 × 成交量，**越大通常流动性越好** |
| `last_bar_dollar_vol` | 窗口内**最后一个交易日**的成交额（用于对照） |

这是在 **固定股票池（nasdaq100 或 sp500）里做流动性排序**，方便你理解「池子」和「横截面比较」，**不是买卖建议**。

### B）`qrun` 跑完后终端里几段典型结果

- **`IC` / `Rank IC`**：模型预测的分数，和未来收益**相关性**的大致指标（越高说明预测越有用，但仍要看回测与样本外）。
- **`The following are prediction results`**：某个交易日上，部分股票的**模型打分**示例。
- **`excess return without cost` / `with cost`**：相对基准（这里配置里是 **SPY**）的超额收益风险指标；**`mean`**、**`annualized_return`**、**`max_drawdown`** 等是常见读法。
- **`mlruns/` 目录**：MLflow 本地实验记录（指标、参数、部分产物）。若安装 MLflow，可在项目根执行 `mlflow ui` 用浏览器看（可选）。

### C）数据日期

当前官方 **`us_data` 日线往往只到约 2020-11**，所以所有示例的截止日期都**卡在历史区间**，**不是**实时 2026 年行情。要更新到更近的日期，需要按 [Qlib 数据文档](https://qlib.readthedocs.io/) 自行拉新数据或换数据源，这已超出本骨架默认范围。

## 4. 和两份研究报告怎么对照着用？

| 报告里写的 | 本仓库对应关系 |
|------------|----------------|
| Qlib、VectorBT、Alpaca | 通过 `requirements.txt` **安装库** + `config/`、`scripts/` **接起来用** |
| FinRL、FinGPT、Lean、freqtrade 等 | **未**作为子项目克隆进本仓库；需要时应在**别的目录**单独 clone 或 pip 安装，再自行对接 |

若你希望「目录里真的有一份 Qlib 源码方便改」，可以在**本仓库外**执行 `git clone https://github.com/microsoft/qlib.git`，与当前项目并行，而不是混在一个文件夹里。
