## SEC 源头与计算链

### 1. 前一交易日匹配没有错位

使用 provider 日历精确映射前一交易日；join 为 one-to-one，所有命中满足 `filed_date <= information_session < signal_session`。日历第一日无法得到前一日，形成起点缺失，完全落在价格暖启动范围。

未匹配不等于未披露：SPY/QQQ 是构建器明确排除的基准 ETF，各缺 1,047 格；EA 也是 1,047 格，但属于下面的缓存衔接缺陷。其余集中在 ABNB 107 格、MRVL 151 格、CEG 27 格、SNOW 23 格及其他标的首日。全量逐行依据在 `eligibility.parquet`。

### 2. reported 策略过滤是长期覆盖损失的主要来源

原值 `assets-equity` 即使有限，也因来源为 derived 被过滤。这是实验明示规则，不是计算错误，本次没有放宽。

本次检查了 404 个非 reported 的 ticker/申报编号/财务期组合，对应 23,952 个有快照的信号格：所有组合在该份缓存申报、该财务期的所有币种中，都没有规范映射的直接 total-liabilities 事实。例如 AMD 的 raw CompanyFacts 根本没有 `us-gaap:Liabilities` 标签。

这些缺失单元标记 `INVALID_DECLARED_GAP`，杠杆输入保持 null；声明严格限定为**当前缓存、该申报期、直接总负债字段缺失**，不声称企业所有 SEC 文档都没有负债信息，也不拿 assets-equity 伪装成 reported。见 `leverage_source_gaps.csv` 和 `gap_status.parquet`。

### 3. TTM：缺字段、缺全年桥接、缺同比分别保留证据

`ttm_calculation_causes.csv` 按具体申报/字段记录原因。其 rows 是“缺失指标×股票日”，两个指标缺失会重复，不能当独占样本损失。代表案例原始 records、币种、单位、日期、编号、标准化行均写入 `sec_trace_cases.json`。

- **ABNB / MRVL / CEG**：当前 CIK 缓存缺少当时可见的年度净利润记录，季度虽有同比，但无法组成 FY+YTD−prior-YTD。ABNB 原始净利润最早申报 2021-05-14，首个 FY 申报 2022-02-25；MRVL 当前 CIK 为 `0001835632`，最早申报 2021-06-09、首个 FY 2022-03-10。缺口声明仅限当前 CIK 缓存，不声称前身实体/招股书/全部档案不可得。
- **PAYX**：规范 net_income 在一些申报中缺失，raw 有 `NetIncomeLossAvailableToCommonStockholdersBasic`。该指标不能未经语义核对就替代合并净利润；保持未验证/null，而不是宣称没有披露。926 个有快照股票日缺两个 TTM 比率。
- **FISV**：早期桥接缺 operating cash flow FY，raw 有 continuing-operations 标签。持续经营现金流与总经营现金流不当然等价，本次未扩标签。
- **TSLA、FAST、MAR、SWKS、SBUX、TMUS**：所选修订申报仅有股数，覆盖掉前一份质量快照；对应 117、45、25、78、50、3 个信号格，CEG 普通 10-K 另有 53 格。旧代码不是逐字段合并修订申报。贸然前填可能掩盖真实更正，本次保留 null 和编号，不把前填当最小修复。
- **PDD**：原提取器固定优先 USD，但 `0001104659-20-125780` 的人民币 records 同时包含 2019/2020 前三季，美元 records 只有 2020 年。其缺同比是提取币种造成，不是源头没有。

本次完整回放确认实现与原件一致，不等于独立证明所有 TTM 非空值的财务语义正确。桥接目前依赖 FY/fiscal_period 和最近候选，未全面认证财年持续期、重述与同比一致性；此限制不能因样本数增加而消失。

## 最小修复及覆盖影响

1. `scripts/build_sec_fundamentals.py`：当前 ticker 映射缺失时，查本地 SEC submissions 的 tickers；只接受唯一 CIK，校验目录与 payload 身份。EA 对应 `0000712515`，本地 submissions 明示 `EA`，companyfacts 已存在，恢复 1,374 条 facts。歧义/目录不符直接报错，不猜测、不下载。
2. `src/us_quant/fundamentals.py`：`extract_canonical_facts(..., monetary_unit='CNY')` 支持显式、已核对的披露币种；保留默认选择以重放历史。指定币种不存在则报错，不换汇、不混币、不补值。诊断仅对 PDD 调用，生成独立 CNY facts/snapshots。

增量全部来自 EA。EA 在首折暖启动结束后仍缺 cash_conversion_ttm，2022-02-08 申报后恢复，因此不能增加首折训练。PDD 恢复的是信号日 2020-11-17—2021-04-30 期间的 TTM，但仍被价格暖启动过滤，完整融合样本增量为零。PDD 切币也会改变其他非空数值；这是独立诊断产物，未替换原预测或重新声称原模型收益。

## 对价格基线的影响

只按价格特征、标签和边界判断，三折训练原可用 **3,321 / 26,664 / 50,146** 行；同样本消融把它限制为 **2,304 / 18,739 / 35,651**，额外去掉 **1,017 / 7,925 / 14,495** 行。

这对“在完全相同股票日比较价格、质量、融合”是有意设计；对“价格模型自身可用样本”则是不必要的限制。报告同时给两种覆盖，不偷偷更改已有消融。此次没有训练独立价格模型或把新的覆盖提升当成预测能力。
