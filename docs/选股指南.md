# 如何在本项目中增加「选股」能力

「选股」可以分三层理解，本项目里分别对应不同入口。

## 1. 股票池（Universe）

先确定你在哪一批票里做研究，避免在全市场盲目扫。

| 做法 | 说明 |
|------|------|
| **用 Qlib 内置池** | `sp500`、`nasdaq100`、`all`（见 `~/.qlib/qlib_data/us_data/instruments/*.txt`） |
| **改 YAML** | 在 `config/qlib/workflow_*.yaml` 里改 `data_handler_config.instruments` |
| **自定义列表** | 新建 `instruments/my_pool.txt`（格式与官方一致：`symbol\tstart\tend`），再在配置里指向该文件（需查阅 [Qlib 文档](https://qlib.readthedocs.io/) 中 Instrument 配置） |

你已有的 **`qrun` 工作流**本质上已经固定了一个 universe（例如 nasdaq100），模型与回测都在这个池子里进行。

## 2. 因子 / 模型选股（横截面打分）

这是量化里最常见的「选股」：**每个交易日对 universe 内股票打分，再按分数做多空或 Top-K**。

在本仓库中：

- **`qrun` + LightGBM + Alpha158**：模型输出对未来收益的预测，**`TopkDropoutStrategy`** 按预测分自动做「买强卖弱」，这已经是 **ML 驱动的选股 + 组合构建**。
- 若要换因子：改 `handler`（如 Alpha360）、换 `model`、或在 Qlib 里自定义 `Dataset` / 标签。

进阶方向（需自行查阅 Qlib）：多因子合成、行业中性、风险模型约束等。

## 3. 规则筛选（初筛 / 风控）

在进模型前，用规则去掉流动性差、停牌多、极端价的标的。

本仓库新增示例脚本（**不替代** `qrun`，仅演示规则层）：

```bash
.venv/bin/python scripts/screen_liquidity_qlib.py --market nasdaq100 --top 20 --lookback 20
```

思路：用本地 `us_data` 计算近 N 日平均成交额（价 × 量），输出横截面排名。你可仿照该脚本改为：

- 最低日均成交额阈值；
- 最低收盘价；
- 结合波动率、上市天数等（仍用 `D.features` 拉字段即可）。

## 4. 与 VectorBT 路线的关系

`scripts/backtest_vectorbt_baseline.py` 当前是 **单标的** 技术策略演示。若要做 **多标的轮动选股**，需要：

- 用 `yfinance` / Alpaca 拉多 ticker 面板数据，或
- 以 Qlib 输出每日候选列表，再接到 VectorBT 做向量化回测。

这是另一条工程路径，与 Qlib 流水线二选一或分段衔接即可。

## 5. 实盘 / 纸面

选股结果落地为订单时，沿用 `scripts/alpaca_paper_executor.py`：把「当日目标持仓」或「买卖指令」写成 `signals/*.json`，并保留 Kill-switch 与仓位风控。

---

**小结**：  
- **最强扩展**：在现有 **`qrun` 工作流**上改 universe、特征与模型，即完整的横截面选股。  
- **最轻扩展**：跑 **`screen_liquidity_qlib.py`** 做流动性初筛，再把股票池收窄后用于自建策略或人工研究。
